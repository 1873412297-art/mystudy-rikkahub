# 酒馆开场选择页视觉收敛设计

## 目标

基于华为 MNA-AL00 真机截图，修复开场选择页中破图头像、状态摘要空泛、长开场页码不可见和切换控件不稳定的问题。保留角色卡自带的正文与状态面板风格，不做无关重构。

## 视觉原则

- 宿主界面保持克制，让角色卡内容成为视觉主体。
- 重要操作和当前位置始终可见，不依赖正文长度。
- 资源失败必须优雅降级，不显示浏览器破图图标或替代文本。
- 使用现有 Material 主题颜色和字号体系，兼容亮色、暗色及系统字体缩放。

## 设计

### 头像降级

酒馆 WebView 中的图片头像加载失败时，就地替换为与头像相同尺寸和圆角的单字占位。占位取角色名首个非空字符；图片使用空替代文本，避免加载失败期间显示长文本。成功加载时继续显示原图。

### 紧凑状态摘要

浮动状态栏优先从当前候选开场的状态变量中提取时间与地点，形成类似“申时 · 顾家镇·潘寡妇宅”的单行摘要。无法提取时沿用状态块标题；两者都缺失时才显示“状态栏”。“更新中 / 已更新”保留为弱化的次要状态。

### 稳定的开场导航

开场页码改为固定在 WebView 可视区域底部中央、输入框上方的轻量胶囊，长开场滚动时仍可见。左右切换按钮固定在可视区域两侧中部，触控目标不少于 44 CSS 像素；到达首尾时隐藏不可用方向。控件使用主题表面色与描边，不使用模糊玻璃效果。

### 正文节奏

仅针对开场选择态小幅收紧头像、角色名与正文的纵向间距，并把正文行高控制在舒适范围。不开启新的卡片容器，不覆盖角色卡注入的文本颜色、强调色或自定义状态面板 CSS。

## 数据流与边界

- `TavernOpeningStage` 继续提供隔离候选会话与变量。
- `StatusHudPresentation` 负责生成稳定的紧凑摘要，不在 Compose 层解析展示文本。
- `tavern-conversation.html` 只负责头像降级、导航定位和开场态排版。
- 展开的富状态面板保持现有 WebView 内容与上下文注入链路，不调整角色卡内部结构。

## 异常处理

- 头像 URL 为空或加载失败：显示单字占位。
- 时间或地点字段缺失、类型异常：跳过该字段并回退到状态块标题。
- 开场候选仍在加载：页码继续显示加载状态，切换按钮遵守当前可用范围。
- 系统启用减少动态效果：继续禁用开场切换动画。

## 验证

- JVM 回归测试：状态摘要提取、字段缺失回退、现有状态栏展示逻辑。
- HTML/脚本回归测试：头像 `error` 降级、空替代文本、固定页码与导航控件样式。
- 构建：关联单元测试与 `:app:assembleDebug`。
- 华为 MNA-AL00：检查 1/5、3/5、5/5，长正文滚动、左右往返、破图头像、紧凑状态摘要和展开状态面板；检查应用进程无 `FATAL` 或 `AndroidRuntime` 崩溃。

## 非目标

- 不重新设计角色卡自带的富状态面板。
- 不修改角色卡内容、图片资源或世界书数据。
- 不改变开场候选提交、状态变量隔离或脚本权限语义。
